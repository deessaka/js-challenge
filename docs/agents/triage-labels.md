# Triage Labels

| Rôle canonique | Label GitHub | Signification |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer par le mainteneur |
| `needs-info` | `needs-info` | Informations supplémentaires requises |
| `ready-for-agent` | `ready-for-agent` | Spécification complète et exécutable par un agent |
| `ready-for-human` | `ready-for-human` | Intervention humaine requise |
| `wontfix` | `wontfix` | Ne sera pas traité |

Lorsqu’une skill mentionne un rôle de triage, utiliser le label GitHub correspondant dans ce tableau.
