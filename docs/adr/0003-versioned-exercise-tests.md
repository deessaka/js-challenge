# Conserver les tests d’exercices dans Git

Le panel admin gère le contenu pédagogique et vérifie la présence des tests, mais n’édite pas leur JavaScript en V1. Les tests restent versionnés dans Git afin d’éviter qu’un code arbitraire soit stocké et exécuté depuis l’interface d’administration, tout en conservant une revue et une traçabilité adaptées aux changements de logique d’évaluation.
