# Les notions au programme

Chaque exercice Codojo cible une compétence précise du langage. Le catalogue s’organise autour de trois familles de notions : la transformation de données avec la programmation fonctionnelle, le traitement des chaînes de caractères avec les expressions régulières, et l’écriture d’algorithmes robustes avec les méthodes avancées de tableau.

Chaque famille dispose d’une page dédiée qui présente les méthodes concernées, des exemples commentés, les pièges classiques et les cas limites attendus par la validation officielle.

## Vue d’ensemble

| Famille | Méthodes au cœur des énoncés | Ce que vous apprenez |
| --- | --- | --- |
| [Programmation fonctionnelle](/docs/functional-programming/) | `map`, `filter`, `reduce` | Transformer des collections de façon déclarative, sans modifier vos données sources. |
| [Expressions régulières](/docs/regular-expressions/) | `match`, `test`, `replace` | Décrire un motif pour valider, extraire ou remplacer du texte. |
| [Méthodes avancées](/docs/advanced-methods/) | `every`, `some`, `find` | Formuler une condition sur un ensemble et localiser efficacement l’élément recherché. |

Ces familles se combinent : un exercice de validation de carte bancaire utilise par exemple une expression régulière pour extraire les chiffres, puis une méthode avancée pour vérifier une contrainte sur chacun d’eux.

## Comment progresser

Le parcours est séquentiel : un exercice se débloque lorsque le précédent est terminé. Cette progression est volontaire — chaque étape vous fait rencontrer une notion au moment où elle devient utile.

1. **Consolidez les bases.** Les exercices Facile portent sur des transformations simples : comptage, nettoyage de chaînes, opérations élémentaires sur les tableaux.
2. **Enchaînez les méthodes.** Les exercices Moyen demandent de combiner plusieurs méthodes dans une même solution.
3. **Allez plus loin.** Les exercices Difficile assemblent ces briques dans des algorithmes complets : analyse de texte, simulation, parcours de structures.

> Une solution qui réussit les exemples de l’énoncé ne suffit pas toujours : la validation officielle vérifie aussi les cas limites. Les pages de notions listent ceux qui reviennent le plus souvent.
