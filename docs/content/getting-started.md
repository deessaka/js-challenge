# Commencer avec Codojo

## 1. Ouvrir Codojo

Rendez-vous sur [codojo.ekodev.com](https://codojo.ekodev.com). Créez un compte ou connectez-vous avec votre compte existant.

## 2. Choisir un challenge

Le catalogue présente les challenges disponibles, leur difficulté et leur état de progression. Commencez par un exercice déverrouillé et lisez toute la consigne avant d’écrire du code.

## 3. Comprendre le contrat

Identifiez les paramètres attendus, la valeur de retour, les cas limites et les contraintes. Une solution correcte doit respecter le contrat fonctionnel, pas seulement réussir un exemple.

## 4. Tester votre solution

Exécutez les tests depuis l’interface du challenge. Un test en échec indique le résultat obtenu et vous aide à localiser le comportement à corriger. Vérifiez aussi les cas vides, les valeurs inattendues et les entrées de grande taille.

## 5. Soumettre

Lorsque les tests locaux sont satisfaisants, envoyez votre solution pour la validation officielle. Une soumission est évaluée par le serveur et contribue à votre progression si elle est acceptée.

## Conseils de travail

- Faites une modification à la fois.
- Gardez les fonctions courtes et nommées.
- Testez les cas limites avant d’optimiser.
- N’envoyez jamais de token ou de secret dans le code d’un challenge.

Consultez [le fonctionnement des challenges](/docs/challenges/) pour comprendre les états de progression et [la page CLI](/docs/cli/) si vous préférez travailler dans le terminal.
