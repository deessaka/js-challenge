# Bienvenue dans Codojo

Codojo est un dojo d’entraînement à JavaScript. Vous progressez en résolvant des challenges pratiques, en exécutant leurs tests et en soumettant vos solutions lorsque le résultat vous convient.

## Le parcours Codojo

| Étape       | Objectif                                                   |
| ----------- | ---------------------------------------------------------- |
| Découvrir   | Parcourir le catalogue et choisir un challenge disponible. |
| Comprendre  | Lire les consignes, les contraintes et le code de départ.  |
| Implémenter | Écrire une solution claire et gérer les cas limites.       |
| Vérifier    | Exécuter les tests et corriger les erreurs.                |
| Soumettre   | Envoyer la solution pour la validation officielle.         |
| Progresser  | Consulter les challenges terminés et les points obtenus.   |

## Choisir votre interface

L’[application Web](https://codojo.ekodev.com) permet de commencer rapidement et de suivre votre compte. La [CLI](/docs/cli/) convient au travail dans le terminal et propose une interface interactive pour naviguer, éditer et tester les challenges.

> Commencez simplement : choisissez un challenge, écrivez une solution lisible, exécutez les tests, puis soumettez-la lorsque vous êtes prêt.

Consultez ensuite [le parcours de démarrage](/docs/getting-started/) ou [la référence CLI](/docs/cli/).
