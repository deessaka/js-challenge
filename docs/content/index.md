# Bienvenue dans Codojo

Codojo est un dojo d’entraînement à JavaScript. Vous progressez en résolvant des exercices pratiques, en exécutant leurs tests et en soumettant vos solutions lorsque le résultat vous convient.

## Le parcours Codojo

| Étape       | Objectif                                                    |
| ----------- | ----------------------------------------------------------- |
| Découvrir   | Parcourir le catalogue et choisir un exercice disponible.    |
| Comprendre  | Lire les consignes, les contraintes et le code de départ.    |
| Implémenter | Écrire une solution claire et gérer les cas limites.         |
| Vérifier    | Exécuter les tests et corriger les erreurs.                  |
| Soumettre   | Envoyer la solution pour la validation officielle.           |
| Progresser  | Consulter les exercices terminés et les points obtenus.      |

## Choisir votre interface

L’[application Web](https://codojo.ekodevs.com) permet de commencer rapidement et de suivre votre compte. La [CLI](/docs/cli/) convient au travail dans le terminal et propose une interface interactive pour naviguer, éditer et tester les exercices.

> Commencez simplement : choisissez un exercice, écrivez une solution lisible, exécutez les tests, puis soumettez-la lorsque vous êtes prêt.

## Comprendre les notions travaillées

Chaque exercice cible une compétence précise : programmation fonctionnelle (`map`, `filter`, `reduce`), expressions régulières ou méthodes avancées de tableau. La page [Les notions au programme](/docs/notions/) présente ces trois familles, avec des exemples commentés et les pièges classiques — à lire avant d’attaquer chaque nouvelle famille d’exercices.
