Codojo vous accompagne dans la résolution de challenges JavaScript, depuis la découverte du catalogue jusqu’à la soumission et au suivi de votre progression.

<CardGrid stagger>
  <Card title="Découvrir Codojo" icon="open-book">

    Web.
  </Card>
  <Card title="Résoudre des challenges" icon="document">
    Apprenez à lire les consignes, exécuter les tests et interpréter les résultats avant de
    soumettre.
  </Card>
  <Card title="Travailler dans le terminal" icon="terminal">

## Une documentation centrée sur la pratique

Chaque guide privilégie les étapes directement utilisables et précise l’interface concernée : Web, terminal ou intégration future. Les commandes documentées sont alignées sur les fonctionnalités actuellement disponibles dans le projet.

> Commencez simplement : choisissez un challenge, écrivez une solution lisible, exécutez les tests, puis soumettez-la lorsque vous êtes prêt.

Pour les questions fréquentes, consultez la [configuration](/reference/configuration/) et le [guide de dépannage](/reference/troubleshooting/).
