---
title: Votre premier challenge
description: Réaliser votre première solution JavaScript dans Codojo.
---

## 1. Créer votre compte

Ouvrez [l’application Codojo](https://codojo.ekodev.com) et créez un compte. Après connexion, vous arrivez sur le parcours d’apprentissage et pouvez consulter le catalogue des challenges.

## 2. Choisir un challenge disponible

Commencez par un exercice marqué comme disponible. Lisez son titre, sa difficulté, le nombre de points et sa description complète avant d’écrire du code. Un challenge verrouillé doit être débloqué en suivant l’ordre prévu par votre progression.

## 3. Écrire une première solution

Partez du code de départ fourni lorsqu’il existe. Concentrez-vous d’abord sur le comportement attendu, puis améliorez la lisibilité : noms de variables explicites, fonctions courtes et gestion des cas limites.

## 4. Exécuter les tests

Lancez les tests locaux depuis l’interface prévue. Un résultat échoué est une indication de travail, pas une soumission définitive. Utilisez la description du test et le message d’erreur pour identifier la différence entre le résultat attendu et votre implémentation.

## 5. Soumettre

Lorsque les tests sont satisfaisants, envoyez votre solution avec l’action de soumission officielle. Le serveur exécute la validation et enregistre le résultat pour votre progression.

Pour apprendre le même flux dans le terminal, consultez [l’installation de la CLI](/cli/installation/) puis [les commandes principales](/cli/commands/).
