Codojo est un dojo d’entraînement à JavaScript. Vous progressez en résolvant des challenges pratiques, en exécutant les tests associés et en soumettant vos solutions lorsque le résultat vous convient.

## Le parcours Codojo

Le portail Web sert à créer votre compte, accéder au catalogue et suivre votre progression. La CLI permet de retrouver ce même parcours dans le terminal, avec un éditeur intégré et des commandes adaptées au travail quotidien.

| Étape       | Ce que vous faites                                         |
| ----------- | ---------------------------------------------------------- |
| Découvrir   | Parcourir le catalogue et choisir un challenge disponible. |
| Comprendre  | Lire la description, les contraintes et les indications.   |
| Implémenter | Écrire une solution JavaScript claire et progressive.      |
| Vérifier    | Lancer les tests et corriger les erreurs signalées.        |
| Soumettre   | Envoyer la solution pour une validation officielle.        |
| Progresser  | Consulter les challenges terminés et les points obtenus.   |

## Quelle interface choisir ?

Utilisez l’application Web pour commencer rapidement et visualiser votre compte. Utilisez la [CLI](/cli/installation/) si vous préférez travailler dans le terminal, naviguer avec le clavier et conserver votre flux de développement près de votre éditeur.

La section [VS Code](/vscode/) décrit l’état actuel de l’intégration dédiée. Lorsqu’une fonctionnalité n’est pas encore disponible dans le dépôt, elle est signalée explicitement plutôt que présentée comme une capacité existante.
