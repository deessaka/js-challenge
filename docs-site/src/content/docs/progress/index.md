---
title: Score et progression
description: Comprendre les points, les challenges terminés et le suivi de votre parcours.
---

Codojo transforme les soumissions acceptées en progression visible. Le catalogue indique les challenges terminés et le tableau de bord permet de retrouver vos statistiques de parcours.

## Les points

Chaque challenge possède une valeur en points définie par le serveur. Les points sont attribués selon la progression enregistrée ; ils ne doivent pas être calculés ou envoyés par le client.

## Le tableau de bord

La commande suivante affiche l’adresse du tableau de bord Web :

```bash
codojo dashboard
```

Vous pouvez aussi ouvrir directement [l’application Codojo](https://codojo.ekodev.com) après vous être connecté.

## Le leaderboard

Le leaderboard permet de comparer la progression enregistrée entre les participants. Utilisez-le comme un repère de régularité et de compréhension, pas comme une raison de soumettre du code non vérifié.

La meilleure progression est généralement obtenue en revenant sur les erreurs, en améliorant la lisibilité et en validant chaque étape avec les tests.
