Chaque challenge Codojo possède un titre, un slug, une difficulté, une valeur en points, une description et un état de progression. Le catalogue vous montre les exercices déjà terminés, disponibles ou encore verrouillés.

## Un parcours progressif

Les challenges suivent une progression. Un exercice verrouillé ne peut pas être ouvert ou exécuté avant d’être disponible. Cette règle est appliquée par l’application et par l’API afin que la progression reste cohérente quelle que soit l’interface utilisée.

## Dry-run et soumission officielle

Le dry-run sert à exécuter votre code sans enregistrer une validation officielle. Il vous permet d’observer les tests, les logs et les erreurs pendant que vous développez. La soumission officielle est l’étape qui enregistre le résultat dans votre parcours.

> Un dry-run réussi est une bonne indication, mais seule la soumission officielle met à jour votre progression.

## Difficulté et points

La difficulté utilise l’échelle kyu : les niveaux 8 et 7 sont les plus accessibles, puis les niveaux deviennent progressivement plus exigeants jusqu’aux niveaux 1. Les points sont attribués par le challenge et servent de référence pour le score.

Pour apprendre à interpréter les résultats avant de soumettre, consultez [Exécuter les tests](/challenges/running-tests/).
